# Terminal Portfolio

A Linux terminal-inspired portfolio website built with React, Vite, and tailwind.

## Features
- **Interactive Shell**: Functional command line interface.
- **File System**: Simulated file system navigation (`cd`, `ls`, `cat`).
- **Commands**: 
  - `about`: Professional summary.
  - `skills`: Skills visualization.
  - `projects`: Project showcase.
  - `experience`: Work history (man-page style).
  - `resume` / `open resume.pdf`: PDF viewer linkage.
  - `contact`: Contact details.
- **Aesthetics**: CRT scanlines, retro fonts, and hacker theme.

## Tech Stack
- React 19
- TypeScript
- Vite
- TailwindCSS v4
- Zustand

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
